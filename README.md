# 🛍️ Shopnest Store – Power BI Dashboard

## 📌 Project Overview

This project is a Power BI dashboard created as part of my Data Analytics capstone project.

The dashboard analyzes Shopnest store data and presents business and sales information through interactive visualizations and key performance indicators.

## 🎯 Project Objectives

- Analyze store sales and business performance
- Identify important trends and patterns in the data
- Create meaningful KPIs for business analysis
- Present data through interactive Power BI dashboards
- Transform raw data into clear and actionable visual insights

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation

## 📊 Dashboard

The dashboard includes multiple visualizations designed to provide an overview of Shopnest's business performance.
